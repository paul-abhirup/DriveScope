# ADR-005: Versioned Evaluation Metrics and Explicit Proxies

## Status
Accepted

## Context
Non-physics simulation metrics risk giving a false sense of safety validation.

## Decision
Version all evaluation metric definitions (e.g. `version=1.0.0`) and explicitly label safety indicators as proxy metrics rather than safety certifications.

## Consequences
Maintains scientific rigor and prevents over-claiming autonomous driving capabilities.
